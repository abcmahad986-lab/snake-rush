## 🎮 How to Equip Heroes

### Step 1: Open Characters Screen
1. From the main menu, click on **"Heroes"** (🎭) button
2. Or navigate to the Characters screen from any menu

### Step 2: Select a Character
1. Browse through all available characters
2. Click on any character you own (not locked)
3. Characters unlock at different levels:
   - **Level 1**: Classic Snake 🐍
   - **Level 2**: Wise Turtle 🐢
   - **Level 3**: Swift Rabbit 🐰
   - **Level 4**: Cunning Fox 🦊
   - **Level 5**: Fire Dragon 🐉
   - **Level 6**: Alpha Wolf 🐺
   - **Level 7**: Majestic Lion 🦁
   - **Level 8**: Soaring Eagle 🦅
   - **Level 9**: Gentle Panda 🐼
   - **Level 10**: Phoenix 🦅
   - **Level 11-25**: More epic and legendary characters!

### Step 3: Equip the Character
1. Once you select a character, you'll see:
   - Character details (name, description, emoji)
   - Available skins for that character
   - **"Equip"** button (if not already equipped)
2. Click **"Equip"** to make this your active character
3. The character will now appear in your games!

### Step 4: Choose a Skin (Optional)
1. Each character has 3 different skins
2. Skins change the colors of your snake in-game
3. Select a skin from the list below the character
4. Click **"Equip Skin"** to apply it
5. Your snake will now use those colors in the game!

---

## 🎨 How It Works In-Game

### Visual Changes
When you equip a hero and skin:
- ✅ **Snake Head**: Uses the skin's head color with glow effect
- ✅ **Snake Body**: Uses the skin's body color with gradient fade
- ✅ **Glow Effect**: Each skin has a unique glow color
- ✅ **Opacity Gradient**: Body segments fade from head to tail

### Example
If you equip:
- **Character**: Fire Dragon 🐉
- **Skin**: Inferno (orange/red colors)

Your snake will appear as:
- **Head**: Bright orange with red glow
- **Body**: Gradient from orange to red
- **Tail**: Fades to darker red
- **Glow**: Fiery orange glow around the head

## 🎯 Skin Unlock Methods

Each character has 3 skins that can be unlocked in different ways:

### 1. Level Skin
- **How to unlock**: Reach the character's unlock level
- **Example**: Fire Dragon unlocks at level 5, so "Inferno" skin is available at level 5
- **Availability**: Automatic when you reach the required level

### 2. Chest Skin
- **How to unlock**: Open chests in the game
- **Example**: "Frost" skin for Fire Dragon can drop from chests
- **Availability**: Random drop from Wooden, Silver, Golden, or Legendary chests

### 3. Achievement Skin
- **How to unlock**: Complete specific achievements
- **Example**: "Shadow" skin for Fire Dragon requires an achievement
- **Availability**: Earned by completing achievement goals

```typescript
  };
  setPlayer(updated);
  savePlayer(updated);
```


### In-Game Rendering
```typescript
// Game uses equipped character skin colors
const getSkinColor = (index, total, isP2) => {
  const characterSkin = player.equippedCharacterSkin;
  const skinColors = characterSkinColors[characterSkin];
  
  if (index === 0) {
    // Head with glow
    return { bg: `rgba(${skinColors.head}, ${opacity})`, shadow: skinColors.glow };
  }
  // Body with gradient
  return { bg: `rgba(${skinColors.body}, ${opacity})`, shadow: 'none' };
};
```
